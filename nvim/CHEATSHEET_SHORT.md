# Neovim Cheat Sheet (Short)

## Core flow
- Find files: `<C-p>` / `<leader>ff`
- Live grep: `<leader>fg` / `<leader>pa`
- Format: `<leader>f`
- TS health checks: `<leader>ch`

## LSP
- Hover: `K`
- Definition: `gd`
- Rename: `<leader>rn`
- Code action: `<leader>ca`
- References panel: `gr` / `<leader>lr`
- Next/prev diagnostic: `]d` / `[d`
- Diagnostics panel: `<leader>xx`

## Completion
- Show menu/docs: `<C-Space>`
- Next/previous: `<C-n>` / `<C-p>`
- Accept: `<C-y>` or `<CR>`

## Harpoon
- Add file: `<leader>ha`
- Menu: `<leader>hh`
- Next/prev: `<leader>hn` / `<leader>hp`
- Jump file: `<leader>h1` `<leader>h2` `<leader>h3` `<leader>h4`

## Tests
- Nearest: `<leader>tn`
- File: `<leader>tf`
- Last: `<leader>tl`

## Git
- LazyGit: `<leader>gg`
- Preview hunk: `<leader>gp`
- Stage hunk: `<leader>gs`

## Buffers and tree
- Next/prev buffer: `<S-l>` / `<S-h>`
- Delete buffer: `<leader>bdd`
- Reveal Neo-tree on the right: `<C-b>`
