# Neovim shortcuts

Leader is **Space**.

| Task | Keys |
| --- | --- |
| Find files / search text | Ctrl-P / Space pp / Space pa |
| Find open buffers / recent files | Space pb / Space pr |
| Clear search highlights | Space h |
| File tree | Ctrl-B / Ctrl-Y / Space rv |
| Built-in file browser | Space pv |
| Previous / next buffer | Shift-H / Shift-L |
| Close buffer / close other buffers | Space bdd / Space bda |
| Format buffer / selection | Space f or :Format / visual F3 with LSP attached |
| Hover / definition / implementation | K / gd / gi |
| Rename / code action | Space rn / Space ca |
| LSP references / TypeScript version | Space vrr / Space cV |
| References / diagnostics panel | gr / Space xx |
| Next / previous diagnostic | ]d / [d |
| Diagnostic popup | Space q |
| Completion menu / next / previous | Ctrl-Space / Ctrl-n / Ctrl-p |
| Accept completion | Ctrl-y / Enter |
| Next / previous snippet placeholder | Tab / Shift-Tab |
| Toggle comment | gcc (line), gc (selection or motion) |
| Add / delete / replace surrounds | sa / sd / sr |
| Substitute word under cursor | Space s |
| Undo tree | Space u |
| LazyGit / current file history | Space lg / Space gh |
| Preview Git hunk | Space gp |
| Review changes / current-file diff | Space gd / Space gD |
| CodeDiff: next/previous hunk / file | ]c/[c / ]f/[f |
| CodeDiff: stage/unstage hunk / file | Space hs/hu / - |
| CodeDiff: layout / help / close | t / g? / q |
| CodeDiff: accept ours / theirs / both | Space co / Space ct / Space cb |
| Shortcut hints | Pause after a prefix for which-key |

Harpoon, Obsidian, editor test shortcuts and Markdown preview are removed.
